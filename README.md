## 📌 GIỚI THIỆU DỰ ÁN

Website giới thiệu năng lực phân phối, trưng bày showroom sản phẩm và nhận đăng ký tư vấn trực tiếp từ kho dành cho **Công ty Sản Xuất Thương Mại Và Dịch Vụ Hưng Vinh Phát**.

Được xây dựng trên nền tảng **Next.js 16 (App Router)** hiện đại, chuẩn SEO, phản hồi siêu nhanh và tối ưu hóa trải nghiệm mượt mà trên cả giao diện Máy tính (Desktop) lẫn Điện thoại (Mobile).

---

## ✨ CÁC TÍNH NĂNG NỔI BẬT

* **🏬 Showroom Sản Phẩm & Thương Hiệu**:
  * Trưng bày các thương hiệu đối tác chính hãng: **Hoa Sen Home**, **Thép Hòa Phát**, **Gạch men Lustra**, **Thiết bị vệ sinh Tuslo**, **Nhôm Trường Thành**, **Lustime**, **VAS**, **Đức Việt**...
  * Bộ lọc theo danh mục: *Sắt & Thép xây dựng*, *Tôn & Nhôm công trình*, *Gạch men ốp lát*, *Thiết bị vệ sinh*, *Ngói & mái lợp*, *Nhựa ốp trang trí*, *Gỗ tự nhiên & công nghiệp*.

* **🔍 Trang Chi Tiết Sản Phẩm Trực Quan (`/product/[id]`)**:
  * Giao diện phẳng mở tràn lề hiện đại, hiển thị đơn giá niêm yết rõ ràng.
  * **Bộ sưu tập ảnh (Gallery) & Lightbox Phóng To**: Nhấp vào ảnh để xem full màn hình với phím tắt điều hướng Trái (`←`) / Phải (`→`) và phím `ESC`.
  * **Form Đăng Ký Tư Vấn & Đặt Hàng Trực Tiếp**: Nhập Họ tên, Số điện thoại và Ghi chú nhu cầu chi tiết (số lượng m², quy cách cắt, giao công trình...) với các ô nhập cố định chiều cao chuẩn chỉnh.

* **💬 Nút Nổi Zalo Chăm Sóc Khách Hàng**:
  * Nút nổi `Liên hệ Zalo` thiết kế mượt mờ nổi ở góc dưới màn hình giúp khách hàng dễ dàng nhắn tin nhận chiết khấu trực tiếp.

* **📱 Tối Ưu Giao Diện Responsive 100%**:
  * Đảm bảo hiển thị hoàn hảo trên mọi kích thước màn hình từ Mobile (<480px), Tablet (<850px) đến Desktop.

## 🚀 HƯỚNG DẪN CÀI ĐẶT & CHẠY LỰC ĐỊA (LOCAL)

### 1. Cài đặt các gói phụ thuộc (Dependencies)
```bash
npm install
```

### 2. Chạy Dev Server giao diện phát triển
```bash
npm run dev
```
Truy cập ứng dụng tại: `http://localhost:3000`

### 3. Biên dịch phiên bản Production (Build)
```bash
npm run build
```
